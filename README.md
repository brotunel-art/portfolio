# Portfolio — Mathis Aurensan

Site statique HTML/CSS pour présenter mes compétences et mes projets de BUT 2 Informatique (2026–2027).

## Fichiers

- `index.html` : page principale du portfolio.
- `style.css` : styles du site.
- `cv-mathis-aurensan-corrige.pdf` : version du CV du 6 novembre 2026 avec QR code vers le dépôt `brotunel-art/portfolio`.

## Mise en ligne sur GitHub

1. Ouvrir le dépôt : https://github.com/brotunel-art/portfolio
2. Importer/remplacer **les trois fichiers** `index.html`, `style.css` et `cv-mathis-aurensan-corrige.pdf` à la racine du dépôt.
3. Faire un commit.
4. Pour publier le site, activer GitHub Pages dans **Settings → Pages** et sélectionner la branche `main`, dossier `/(root)` (si cette option est disponible).
5. Après publication, vérifier l'URL exacte du site et tester les boutons « Mon CV » et « Voir le code sur GitHub ».

> Le lien du QR code **du CV** pointe pour l'instant vers le dépôt GitHub `https://github.com/brotunel-art/portfolio`, et non vers la page GitHub Pages publiée. Pour qu'il pointe directement vers le site, il faut ensuite mettre à jour le QR code dans le CV.
